# Календарь телефона

В приложении: колокольчик → «Календарь телефона».

## Разовый перенос

«Скачать календарь .ics» выгружает только запланированные встречи. Откройте файл в приложении календаря, которое поддерживает импорт. В HTMLPreview доступен этот вариант; демонстрационные события не являются реальными планами пары. Импорт — разовая копия, изменения и отмены не обновляются, повторный импорт может создать дубликаты.

## Автоматическая подписка

Требуется работающий сервер приложения с постоянной SQLite-базой, HTTPS и `PUBLIC_ORIGIN=https://адрес-сайта` (на Render также поддержан `RENDER_EXTERNAL_URL`). Покупать домен необязательно: подходит HTTPS-адрес хостинга. GitHub HTMLPreview не исполняет серверные API.

Подключите пару, затем нажмите «Подключить календарь телефона».

- iPhone: «Открыть подписку на iPhone», подтвердить подписку. Не включайте удаление напоминаний. Разрешите уведомления для приложения «Календарь» в настройках iOS.
- Android / Google Calendar: скопируйте HTTPS-ссылку. В веб-версии Google Calendar добавьте её через «Другие календари» → «Добавить по URL». Включите календарь и его уведомления на телефоне. Некоторые клиенты игнорируют импортированные VALARM: настройте уведомления для подписного календаря отдельно, если приложение позволяет.
- Каждый партнёр подключает свою подписку на своём устройстве.

Это односторонняя подписка из «Вдвоём». Добавление, редактирование и удаление выполняются здесь. Обновление на телефоне происходит по расписанию провайдера календаря; мгновенная доставка не гарантируется. Параметр обновления ленты — рекомендация, провайдер может его игнорировать. Это отдельно от веб-пушей о действиях партнёра, которые уже есть в приложении.

Файл задаёт напоминание за час до события, без времени — в 09:00 его дня. Часы трактуются в часовом поясе календаря телефона. Встречи без времени отображаются как события на весь день. Длительность встреч с временем — один час, поскольку в модели нет времени окончания. Реальную доставку уведомления нужно проверить на устройстве: разрешения, настройки календаря и режим фокусирования могут влиять на неё.

## Приватность

Передаются стабильный идентификатор, версия, дата/время и название свидания; для 18+ используется «Время для двоих». Заметки, место, продолжения, тип секса, варианты, позы и личные оценки не передаются. Планы становятся доступны выбранному провайдеру календаря.

Секретная ссылка даёт доступ к запланированным встречам пары без браузерной сессии — так работают подписки календарей. Не публикуйте её и не записывайте пути `/api/calendar/feed/` в журналы прокси. В базе хранится только хеш токена. Создание новой ссылки отзывает предыдущую ссылку этого участника; подписка партнёра продолжает работать. «Отключить подписку» отзывает доступ. Уже загруженные записи могут остаться в кеше телефона — удалите там подписной календарь.
